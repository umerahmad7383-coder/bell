The Last Bell

Class was never dismissed.

Online co-op horror for 2 to 8 friends. Find the fuses, get the keys, reach the gate before the Headmaster finds you. The Windows app plays fullscreen, works with Xbox and PlayStation controllers, and updates itself.

Download for WindowsWindows 10 and 11 · 64-bit · free No install? Play in your browser. Same game, same friends.

Installing

  1. Open the file you downloaded. It is called The-Last-Bell-Setup.exe.
  2. If Windows says it protected your PC, click “More info”, then “Run anyway”. The game is new and not signed by a big publisher yet, so Windows does not recognise it.
  3. Choose where to install it, then Install. You get a desktop shortcut and a Start menu entry.
  4. Type a name, create a lobby, and send your friends the code. Friends on the website and friends on the app can play in the same lobby.

F11 or Alt+Enter switches between fullscreen and a window. When a new version is out, the game downloads it while you play and installs it the next time you start.

What you need

System
Windows 10 or 11, 64-bit
Graphics
Any graphics card from the last 8 years. Graphics settings go from Low (older laptops) to Ultra.
Internet
Needed: every match is online
Disk
About 400 MB
Sound
Headphones. You will want to hear where he is.

Uninstall any time from Windows Settings → Apps.
